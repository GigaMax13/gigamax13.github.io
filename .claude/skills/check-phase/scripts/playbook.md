# check-phase playbook


# check-phase

Verify current branch fully implements all phase requirements. Creates `$DEV_DIR/review.md` with ONLY gaps; deletes it if all requirements met.

## Input

```bash
/check-phase m1  # optional phase (m1, m1.2); auto-detects latest if omitted
```

## Workflow

### 1. Resolve dev directory

```bash
DEV_DIR=$(_sh="${AGENTS_SKILLS_HOME:-"${CLAUDE_PROJECT_DIR:-.}"/.claude}"; [ -f "$_sh/skills/verify-rules/scripts/resolve-dev.sh" ] || _sh="$HOME/.claude"; bash "$_sh/skills/verify-rules/scripts/resolve-dev.sh")
```

### 2. Detect Phase

```bash
INPUT=$(cat); PHASE_INPUT=$(echo "$INPUT" | xargs)
if [ -n "$PHASE_INPUT" ]; then
    PHASE="$PHASE_INPUT"
else
    PHASE=$(ls -1 $DEV_DIR/ 2>/dev/null | grep -E '^m[0-9]+' | sort -V -r | head -1)
fi
[ -z "$PHASE" ] || [ ! -d "$DEV_DIR/$PHASE" ] && echo "Error: No phase found. Provide a phase name or ensure $DEV_DIR/ contains phase directories." && exit 1
```

### 3. Verify Phase Structure

```bash
PHASE_DIR="$DEV_DIR/$PHASE"; PRD_FILE="$PHASE_DIR/PRD.md"; STATE_FILE="$PHASE_DIR/state.md"; TASKS_DIR="$PHASE_DIR/tasks"
[ ! -f "$PRD_FILE" ] && echo "Error: $PRD_FILE not found" && exit 1
[ ! -f "$STATE_FILE" ] && echo "Error: $STATE_FILE not found" && exit 1
[ ! -d "$TASKS_DIR" ] && echo "Error: $TASKS_DIR not found" && exit 1
```

### 4. Gather Branch Changes

```bash
BRANCH=$(git branch --show-current)
CHANGED_FILES=$(git diff main...HEAD --name-only 2>/dev/null)
COMMIT_COUNT=$(git log main..HEAD --oneline 2>/dev/null | wc -l | tr -d ' ')
COMMIT_LOG=$(git log main..HEAD --oneline 2>/dev/null)
FULL_DIFF=$(git diff main...HEAD 2>/dev/null)
```

### 5. Parse PRD.md

Extract requirements, acceptance criteria (`- [ ]`/`- [x]`), and Linear IDs (`[A-Z]+-[0-9]+`).

```bash
PRD_CONTENT=$(cat "$PRD_FILE")
PRD_REQUIREMENTS=$(echo "$PRD_CONTENT" | grep -E '^\s*[-*]\s|^\s*\d+\.' | sed 's/^\s*[-*]\s*//' | sed 's/^\s*[0-9]*\.\s*//')
PRD_CHECKBOXES=$(echo "$PRD_CONTENT" | grep -E '^\s*- \[.?\]' | sed 's/^\s*- \[.\?\]\s*//')
PRD_LINEAR_IDS=$(echo "$PRD_CONTENT" | grep -oE '[A-Z]+-[0-9]+' | sort -u)
```

### 6. Parse Task Files

For each `.md` in `tasks/`, extract title (first `#`), acceptance criteria, Linear IDs.

```bash
for TASK_FILE in $(ls "$TASKS_DIR"/*.md 2>/dev/null); do
    TASK_NAME=$(basename "$TASK_FILE")
    TASK_TITLE=$(grep -m1 '^#' "$TASK_FILE" | sed 's/^#\+\s*//')
    TASK_CRITERIA=$(grep -E '^\s*- \[.?\]' "$TASK_FILE")
    TASK_LINEAR_IDS=$(grep -oE '[A-Z]+-[0-9]+' "$TASK_FILE" | sort -u)
done
```

### 7. Parse state.md

```bash
COMPLETED_TASKS=$(grep -E '^\s*- \[x\]' "$STATE_FILE" | sed 's/.*\] //' | cut -d' ' -f1)
PENDING_TASKS=$(grep -E '^\s*- \[ \]' "$STATE_FILE" | sed 's/.*\] //' | cut -d' ' -f1)
```

### 8. Fetch Linear Issues (read-only, skip if CLI unavailable)

```bash
ALL_LINEAR_IDS=$(echo -e "${PRD_LINEAR_IDS}\n${TASK_LINEAR_IDS}" | sort -u | grep -v '^$')
for ISSUE_ID in $ALL_LINEAR_IDS; do
    ISSUE_JSON=$(linear issue view "$ISSUE_ID" --json 2>/dev/null)
    if [ -n "$ISSUE_JSON" ] && [ "$ISSUE_JSON" != "null" ]; then
        ISSUE_TITLE=$(echo "$ISSUE_JSON" | jq -r '.title // empty' 2>/dev/null)
        ISSUE_DESC=$(echo "$ISSUE_JSON" | jq -r '.description // empty' 2>/dev/null)
    fi
done
```

### 9. Analyze Coverage

For each task/criterion, check if branch diff addresses it via keyword search in changed files and diff. Uncertain = missing.

### 10. Cross-Reference state.md

Flag mismatches:
- `[x]` but no branch changes for that task
- `[ ]` but implementation present in diff

### 11. Generate review.md

**If ALL requirements met:**

```bash
if [ -f $DEV_DIR/review.md ]; then rm $DEV_DIR/review.md && echo "All requirements met - review.md removed"; fi
echo "Phase $PHASE: All requirements verified"
exit 0
```

**If gaps found:**

```bash
mkdir -p $DEV_DIR
cat > $DEV_DIR/review.md << 'REVIEWEOF'
# Phase Verification: $PHASE

*Generated: $(date '+%Y-%m-%d %H:%M:%S')*
*Branch: $BRANCH ($COMMIT_COUNT commits ahead of main)*

## Summary

- Not Implemented: N
- Missing Tests: N
- state.md Mismatch: N
- Unverifiable Tasks: N
- **Total Gaps: N**

## Task: [task-filename.md] - Title
**state.md:** [ ] / [x] | **Linear:** TEAM-XXX

### Not Implemented
- [ ] Criterion that is missing

### Missing Tests
- [ ] Tests for specific functionality

### state.md Mismatch
- [ ] Marked complete but no related changes on branch

## PRD Gaps
- [ ] PRD requirement not covered by any task or implementation

## Linear Gaps
- [ ] Additional requirement from TEAM-XXX not addressed

## Unverifiable
- task-file.md - Title (no acceptance criteria)

---
*Generated by check-phase from $DEV_DIR/$PHASE*
REVIEWEOF

GAPS=$(grep -c '^- \[ \]' $DEV_DIR/review.md 2>/dev/null || echo '0')
echo "Phase $PHASE: $GAPS gaps found — see $DEV_DIR/review.md"
exit 1
```

## Categories

| Category | Meaning |
|----------|---------|
| Not Implemented | No matching changes in branch diff |
| Missing Tests | Implementation exists but no test coverage |
| state.md Mismatch | Completion status disagrees with branch evidence |
| Unverifiable | Task has no acceptance criteria |
| PRD Gaps | PRD requirement not covered by any task/implementation |
| Linear Gaps | Linear issue requirement not addressed |

## Rules

1. review.md contains ONLY gaps
2. Delete review.md when all requirements met
3. NO CODE CHANGES — only create/delete review.md
4. NO LINEAR UPDATES — read-only
5. NO state.md MODIFICATIONS — report mismatches, don't fix
6. Uncertain = missing
7. Each run overwrites review.md
8. Skip gracefully if Linear CLI unavailable

## Exit Criteria

- [ ] Phase directory validated (PRD.md, state.md, tasks/)
- [ ] Branch changes gathered (git diff main...HEAD)
- [ ] PRD.md and all task files parsed for requirements/Linear IDs
- [ ] state.md parsed for completion status
- [ ] Linear issues fetched (read-only, skipped if CLI unavailable)
- [ ] Each requirement analyzed against branch diff
- [ ] state.md cross-referenced with actual changes
- [ ] review.md created with gaps OR deleted if all met
- [ ] Exit 0 if all met, exit 1 if gaps found
